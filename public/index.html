Get started

One command to get going.

Install the latest version from GitHub. You’ll need Python 3.10 or newer.

curl -fsSL https://xernel.vercel.app/install.sh | sh

On Termux, first run pkg install python curl. The installer puts Xernel in your user bin directory.
